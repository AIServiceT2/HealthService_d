## 질문지 검토 (5단계)

> Claude에게 질문지를 보여 주고 '빠진 관점'을 물어봅니다. 제안을 그대로 넣지 말고, 채택한 것과 버린 것을 이유와 함께 적습니다.

| AI 제안 | 채택 / 보류 | 이유 |
| --- | --- | --- |
| 질문 8의 첫 문장 "시나리오를 하나 들어 주실 수 있습니까?"는 예/아니오로 끝날 수 있으니 "어떤 시나리오로 직접 확인해 보시겠습니까?"로 바꾸기 | 채택 | 좋은 질문의 조건 ①(예/아니오로 끝나지 않는다)에 어긋남. 질문 8 문구만 고치면 됨 |
| 서비스를 모바일 앱으로 낼지 웹으로 낼지 묻기 (사진 업로드, 운동 중 모드, 리플레이 화면이 모두 영향을 받음) | 채택 | 질문지에 플랫폼 관점이 없음. 질문이 이미 10개라 새 질문 대신 질문 5(우선순위·범위)의 꼬리 질문으로 넣음. 기획서 v4에서는 사진 업로드 대신 카메라 인식·건강 앱 연동이 영향을 받음 |
| 미성년자(만 14세 미만)도 이용하는지 묻기. 위치·건강 정보 동의 절차가 달라짐 | 채택 | 1-3 ② 검색어(미성년자 위치정보 동의)에서 나온 관점인데 질문지에 없음. 질문 7(개인정보)의 꼬리 질문으로 넣음 |

| 질문 6이 "AI가 의심 사유를 띄운다"는 우리 설계를 전제로 하므로, AI가 검토를 돕는 방식 자체를 열린 질문으로 바꾸기 | 보류 | 전제가 있지만 구체적인 사례로 물어야 책임 소재에 대한 답을 얻을 수 있음(조건 ②). 미팅에서 클라이언트가 AI 역할 자체를 바꾸자고 하면 그때 꼬리 질문으로 다룸 |
| LLM API 비용과 서비스 운영 비용을 누가 부담하는지 묻기 | 보류 | 8주 MVP 범위를 정하는 데 직접 필요하지 않고, 질문 시간이 약 12분이라 우선순위가 낮음 |
| 수익 모델(유료 구독, 광고 등)을 묻기 | 보류 | 제안서 범위가 MVP 기능과 상태 흐름이라 이번 미팅의 결정 사항이 아님 |
