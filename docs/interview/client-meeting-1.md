## 1. 전문가 피드백 요약

| 주제          | 피드백                                                                                                                                                                                      |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 규모와 방향   | 5명·8주에 비해 프로젝트가 크다. 게임과 운동 중 방향을 정해야 하며, 게임으로 가면 난이도가 높다. 운동에 집중하는 쪽이 낫다                                                                   |
| 대상과 리텐션 | 리텐션 요소가 가장 중요하다. 초보 운동인은 자세와 운동 플랜을 궁금해한다. 지금 구조는 초보보다 꾸준히 반복해서 운동하는 사람(러닝 크루 등)에게 더 맞는다                                    |
| 즉시 피드백   | 성취감은 즉시 피드백에서 나온다. 누군가의 승인을 기다리면 성취감과 리텐션이 떨어진다                                                                                                        |
| 자세 인식     | 자세 인식 모델이 가장 중요하고, 자세 정확도를 높이는 것이 최우선이다. MediaPipe, Teachable Machine 등 여러 모델을 써 보고 장단점을 기록해 선정 근거를 남겨라. 온디바이스 AI를 하나 사용하라 |
| 검토 구조     | 다른 길드원 검토는 보상이 배지뿐이라 동기가 없고, 다른 길드만 이득을 본다. AI가 승인하고 일부만 사람이 확인하는 구조가 낫다. AI 판단이 기준에 못 미치면 사람에게 넘긴다                     |
| 회수          | 보스가 이미 쓰러진 뒤 회수하면 보스가 다시 살아나는가? 아이템을 이미 썼다면 어떻게 회수하는가? 회수가 가능한 경우와 불가능한 경우의 플로우를 정리하라                                       |
| LLM           | 지금 LLM의 가치가 약하다. 자세 교정 추천, 성장 리포트 등을 추가하라. LLM이 언제 필요한지 구체적으로 정리하고, 세션이 끊기거나 기억을 잃었을 때 다시 응답하는 방법을 설계하라                |
| 반복 처리     | 반복되는 요청을 어떻게 처리하는지 설계에 잘 드러내라                                                                                                                                        |
| 사용성        | 운동 중에는 화면 터치가 어렵다. 음성 인식이나 동작 감지로 대신하는 방법을 고려하라                                                                                                          |

## 2. 5-5 질문 답변

### 질문 1. 성공 지표

| 지표                                        | 고객 답변                                 |
| ------------------------------------------- | ----------------------------------------- |
| 처음 제출한 사람이 4주 뒤에도 제출하는 비율 | 30~40% 이상                               |
| 사용자당 주간 제출                          | 주 3건 이상                               |
| 주간 레이드 참여율                          | 50% 이상                                  |
| 확인 방법                                   | 제출 이력을 로그로 저장하고 그래프로 확인 |

### 질문 2. 검토 주체

- 혼합 방식. AI 판단 확신도가 90% 이상이면 AI가 승인하고, 90% 미만이면 사람이 확인한다.
- 검토자가 볼 수 있는 것: 관절 선, 운동 종류, 제출 간격 통계
- 검토자에게 보여 주지 않는 것: 얼굴, 나이, 길드명

### 질문 3. 일일 상한

- 상한이 없으면 보상 때문에 결국 게임처럼 변한다.
- 상한을 두고, 넘은 운동량은 기록하되 보상은 0으로 한다.
- 예시: 스쿼트 200회, 러닝 10km

| 하루 제출 건수 | 300건                                               |
