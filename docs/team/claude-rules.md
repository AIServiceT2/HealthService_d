# 팀 CLAUDE.md 규칙 합의 기록

> **저장 위치:** `docs/team/claude-rules.md`

> **사용 방법**
> 1. 각자 "Claude가 같은 말을 반복하게 만든 것", "팀이 같은 방식으로 해야 하는 것"을 **하나씩** 후보로 적습니다.
> 2. 후보마다 **어디에 적을지**부터 정합니다. 개인 / 팀 / 로컬. 판단 기준은 아래 3줄입니다.
> 3. **팀**으로 정한 것만 `CLAUDE.md`에 옮깁니다. 이 파일은 합의 기록이고, `CLAUDE.md`는 **짧게**(200줄 이하) 둡니다.
> 4. 개인 규칙과 팀 규칙이 **모순되지 않는지** 확인합니다. 모순되면 Claude가 아무거나 고릅니다.
> 5. 비밀 값(키·비밀번호)은 어디에도 적지 않습니다. 필요한 환경변수 **이름**만 적습니다.
> 6. `>`로 시작하는 안내 문장은 지워도 됩니다.

## 막을 것 (→ `docs/decisions/permissions.md`로)
> `CLAUDE.md`는 **부탁**이고 `settings.json`은 **막는 장치**입니다. 꼭 막아야 하는 것은 여기에 적고 `settings.json`에도 넣습니다.

| 규칙 | `settings.json`에 넣었나 |
| --- | --- |
| 인수 조건은 사람이 쓴다 | 넣음 (ask `Edit(./docs/requirements/backlog.md)`) |
| MVP 범위를 바꾸지 않는다 | 넣음 (ask `Edit(./docs/decisions/mvp-scope.md)`) |
| 기술 스택을 바꾸거나 고르지 않는다 | 넣음 (ask `Edit(./docs/STACK.md)`) |
| 이미 낸 제안서를 고치지 않는다 | 넣음 (deny `Edit(./docs/proposal/**)`) |
| `main`에 바로 올리지 않는다 | 넣음 (deny `Bash(git push origin main)`). main에서 `git push`만 치면 안 걸림 → GitHub 브랜치 보호가 필요 (permissions.md '알고 있는 한계') |
| force push하지 않는다 | 넣음 (deny `Bash(git push --force *)`, `Bash(git push -f *)`) |
| PR 승인과 병합은 팀원이 한다 | 일부 (ask `Bash(git push *)`). `gh pr merge`는 따로 막지 않음 |
| 비밀 값을 읽거나 적지 않는다 | 넣음 (deny `Read(./.env)`, `Read(./.env.*)`) |
