# 사전 활동 개인 회고 — 손범수 (sonbumsu)

| 항목 | 내용 |
| --- | --- |
| 내가 조사하거나 결정한 것 | ⑤ 문제와 손해 관점에서 초보 운동인이 운동을 그만두는 이유를 조사했다. 5단계 질문지(5-5~5-7)를 작성했고, 미팅에서는 기록자를 맡기로 했다. |
| 내가 만든 근거 카드 (카드 번호) | [5-sonbumsu-1](../docs/domain/cards/5-sonbumsu-1.md) — 초보 러닝 그룹 전향 연구 (Plateau 외, 2022) |
| 내가 직접 확인한 근거 | 초보 러너 프로그램 참가자의 33.3%(21/63)가 부상을 겪었고, 목표 달성률은 74.6%(47/63)였다. 성공 예측 요인은 연령·출석률·초기 자기효능감이었다. |
| AI 답을 확인해 보니 달랐던 것 | 카드의 "성인의 60%" 문장은 원문 확인 내용에 근거가 없었다. 부상률 33.3%를 일일 상한의 근거로 연결한 것도 직접적인 근거가 아니라서 `[추정]`으로 낮췄다. |
| 제안서에서 내가 쓰거나 고친 장 | Claude Code로 제안서 초안(draft.md)을 만들고, 4단계 선정안이 올라온 뒤 Ⅰ-2·Ⅲ·Ⅴ를 채웠다. Ⅶ-18 질문은 내가 쓴 5-5·5-7이 바탕이다. |
| 아직 모르는 것 | "성인의 60%" 문장의 실제 출처와 일일 상한을 몇으로 정해야 하는지. 사진만으로 근력 운동 횟수를 판단할 수 있는지(H3). |
