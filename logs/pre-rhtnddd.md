| 내가 조사하거나 결정한 것 | ① 사람·이용 흐름 관점에서 피트니스 앱 이용자의 운동 빈도·세션 주기·이탈 패턴을 조사함. 03 3-3 시간 규칙의 출처를 보완하고(48시간 제출 기한 ← 1-rhtnddd-1, 일일 상한 ← 5-sonbumsu-1), 3-5 자료 확인 표에 팀 카드 3장(1-rhtnddd-1, 4-Kangjunseok09-1, 5-sonbumsu-1)을 정리함. 미팅에서는 요약·확인자를 맡음 (5-6) |
| 내가 만든 근거 카드 (카드 번호) | [1-rhtnddd-1](../docs/domain/cards/1-rhtnddd-1.md) — Analysis of Training Behavior in Users of a Fitness App (PMC, 2024) |
| 내가 직접 확인한 근거 | 1-rhtnddd-1 원문을 PMC에서 직접 열어 표 1(그래프 부분)을 확인함. 앱 이용자의 훈련 빈도·세션 주기·이탈 패턴이 장기 운동 지속성·유지율과 관련된다는 내용 → 태그 `[추정]` → `[사실]` |
| AI 답을 확인해 보니 달랐던 것 | ① 카드 5-sonbumsu-1의 "초보 러너 33.3% 부상 경험"을 AI가 일일 상한(R1)의 근거로 연결했지만, 카드는 러닝 프로그램의 부상률이지 상한의 효과를 다룬 것이 아니어서 `[추정]`으로 낮춤. ② 내 카드를 "3-3 규칙 1번에 반영"이라고 적었는데, 확인해 보니 48시간 접수 기한과 이탈 패턴은 직접 맞지 않음 → 3-3 출처에 `[추정]`을 붙여 "기한을 너무 길게 두지 않는 근거" 정도로만 남김 ([ai-check-log](../docs/domain/ai-check-log.md)) |
| 제안서에서 내가 쓰거나 고친 장 | 직접 쓴 장은 없음. 내 카드가 제안서 참고자료 [B1]로 인용됨 (배경 근거 3번, 후보 C 근거) |
| 아직 모르는 것 | ① 카드 1-rhtnddd-1의 저자 등 서지정보가 비어 있음 (제안서에도 "서지정보 보완 필요"로 표시됨). ② 논문에서 실제 이탈 시점(몇 주 차에 그만두는지)을 숫자로 뽑지 못해, 미팅에서 "사용자는 언제 그만두나?"(5-7)에 답할 근거가 약함. ③ 카드의 '초보 러너'·'런태기' 표현이 논문 대상자와 맞는지 다시 확인해야 함. ④ 48시간 제출 기한이 지속률에 주는 영향은 근거가 없어 클라이언트 질문 3으로 확인해야 함 |
