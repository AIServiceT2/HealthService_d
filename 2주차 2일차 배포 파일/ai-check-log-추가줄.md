# ai-check-log.md에 이어 쓸 줄 (복사하지 않고 **내용만 붙여넣는** 조각)

> **사용 방법**
> 1. 저장소의 `docs/domain/ai-check-log.md`를 엽니다. `## 요구사항 정리 (1주차 2일차~)` 섹션 표 **맨 아래에 줄만 이어서** 씁니다. **새 섹션을 만들지 않습니다.**
> 2. 오늘 최소 **팀당 3줄**, 그중 **'보류' 1개 이상**입니다. 버린 것을 적는 게 더 중요합니다.
> 3. 예시는 베끼지 말고 우리 팀 내용으로 바꿉니다.
> 4. 이 파일 자체는 저장소에 올리지 않습니다.

'어디서 칸에 쓸 값' 표에 **한 줄**을 더합니다.

| 어디서 | 언제 |
| --- | --- |
| 스택 후보 비교 | 블록 1 ③ 뒤 (추천을 채택했는지, 버렸는지) |
| PRD 초안 | 블록 2 ② 뒤 (새로 들어온 기능을 지웠다면) |
| PRD 대조 | 블록 2 ③ (Claude 지적을 반영하지 않은 것) |
| CLAUDE.md 점검 | 블록 3 A조 (제안을 넣지 않은 것) |
| 권한 규칙 | 블록 3 B조 (Claude가 제안한 규칙을 넣지 않은 것) |
| **뼈대 계획** | **블록 3 뼈대 ① (계획에서 지운 것)** |

예시에도 한 줄 더해 두면 학생이 바로 이해합니다.

| 날짜 | 쓴 사람 | 어디서 | AI가 말한 것 | 확인 결과 | 채택/보류 | 이유 |
