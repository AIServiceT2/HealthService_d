## 오늘 적용할 클로드 에이전틱 코딩 기법

오늘 세 가지가 새로 들어옵니다. 자세한 사용법은 **노션 가이드북**을 보세요.

### 기법 1 — 서브에이전트: 역할과 권한을 묶어 둔다

매번 긴 프롬프트를 치는 대신, **역할·읽을 범위·금지사항을 파일로 고정**해 둡니다.

`.claude/agents/` 아래에 두면 됩니다. 오늘 두 개를 만듭니다.

| 에이전트 | 하는 일 | 중요한 제한 |
| --- | --- | --- |
| `stack-advisor` | 스택 후보 2안을 같은 조건으로 비교 | **파일 수정·설치·실행 안 함. 최종 결정도 안 함** |
| `prd-writer` | 정한 문서를 모아 `PRD.md` 작성 | **새 기능·새 인수 조건 안 만듦. PRD 외 파일 안 고침** |

양식의 맨 위 `tools:` 줄을 보세요. `stack-advisor`에는 `Write`나 `Edit`이 **없습니다.** 쓰고 싶어도 못 씁니다. 이게 프롬프트로 부탁하는 것과 다른 점입니다.

`model: inherit`은 지금 쓰는 모델을 그대로 쓴다는 뜻입니다.

### 기법 2 — CLAUDE.md의 세 층을 구분한다

같은 규칙이라도 **어디에 쓰느냐**에 따라 적용 범위가 다릅니다.

| 적을 것 | 위치 | git 공유 |
| --- | --- | --- |
| 내 취향 (응답 언어, 들여쓰기) | `~/.claude/CLAUDE.md` | 안 됨 |
| **우리 팀 규칙** (스택, 폴더·커밋 규칙, 건드리면 안 되는 것) | `./CLAUDE.md` | **됨** |
| 내 컴퓨터 경로, 테스트용 주소 | `CLAUDE.local.md` | 안 됨 (`.gitignore`) |

**개인 취향을 팀 파일에 쓰면** 다른 팀원에게도 강제됩니다. **팀 규칙을 개인 파일에 쓰면** 나만 지키게 됩니다. 둘 다 흔한 실수입니다.

`CLAUDE.md`는 **200줄 이하**로. 길면 아무도 안 지킵니다. 긴 내용은 문서로 두고 `@docs/STACK.md`처럼 가져옵니다.

### 기법 3 — 부탁과 차단을 구분한다

**오늘 가장 중요한 개념입니다.**

| | `CLAUDE.md` | `.claude/settings.json` |
| --- | --- | --- |
| 성격 | **부탁** (자연어 지침) | **차단** (기술적 제한) |
| 어길 수 있나 | 있음 | 없음 |
| 확인 방법 | 지켜지는지 지켜봄 | **직접 시험해서 막히는 걸 봄** |

권한은 세 가지입니다.

```
allow — 묻지 않고 실행
ask   — 실행 전에 확인을 물음
deny  — 차단
```

**판정 순서는 `deny → ask → allow`입니다. deny가 이깁니다.**

알아 둘 것 네 가지:

- 규칙 이름은 `Edit(경로)`로 씁니다. `Write(경로)`가 아닙니다
- 경로는 `./`로 시작합니다
- `*`는 `/`를 넘지 않고, `**`는 하위 폴더까지 포함합니다
- **명령 하나를 막는 게 전체 차단은 아닙니다.** `curl`을 막아도 다른 경로로 네트워크를 쓸 수 있습니다

`settings.json`에는 **주석을 쓸 수 없습니다.** 그래서 이유와 시험 결과는 `docs/decisions/permissions.md`에 따로 적습니다. 두 파일이 **같은 내용**이어야 합니다.

### B조 — .gitignore 줄 추가 (2분)

`.gitignore`는 **사전활동 때 이미 만들어져 있습니다.** 새로 만들지 말고 **열어서 맨 아래에 줄만 더하세요.** 새 파일을 만들면 기존 내용이 날아갑니다.

받은 `gitignore-추가줄` 조각에서 **공통 + 우리 스택** 것을 넣습니다.

```
# 개인 설정 (저장소에 올리지 않음)
CLAUDE.local.md
.claude/settings.local.json

# 비밀 값 — 절대 올리지 않음
.env
.env.*
!.env.example
```

스택별 항목(`node_modules/`, `__pycache__/` 등)은 조각에서 우리 팀 것만 골라 넣으세요. 이게 빠지면 뼈대를 세운 뒤 PR에 파일이 **수백 개** 올라갑니다.

넣은 뒤 `git status`로 확인합니다. `CLAUDE.local.md`와 `.env`가 **보이면 안 됩니다.**
