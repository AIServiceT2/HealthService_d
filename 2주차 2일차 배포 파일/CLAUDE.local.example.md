# CLAUDE.local.md 예시 (내 컴퓨터에서만 쓰는 지침)

> **저장 위치:** 저장소에 올리지 않음. 복사해 저장소 맨 위(루트)에 `CLAUDE.local.md`로 만듭니다

> **사용 방법**
> 1. 이 파일은 **저장소에 올리지 않습니다.** 내용을 복사해 저장소 루트에 `CLAUDE.local.md`라는 이름으로 만듭니다.
> 2. **git에서 제외해야 합니다.** 저장소 루트의 `.gitignore`에 아래 두 줄이 있는지 확인하고 없으면 추가합니다 (정리 담당이 PR로).
>    ```
>    CLAUDE.local.md
>    .claude/settings.local.json
>    ```
> 3. `git status`에 `CLAUDE.local.md`가 나타나면 제외가 안 된 것입니다. 올리지 마세요.
> 4. **여기에 적을 것:** 내 컴퓨터의 경로, 테스트용 주소, 나만의 작업 습관. **팀이 같이 지킬 것은 `./CLAUDE.md`에** 씁니다.
> 5. **키·비밀번호·토큰은 쓰지 않습니다.** 환경변수 **이름**만 적습니다.
> 6. 팀 `CLAUDE.md`와 **모순되지 않게** 씁니다.
