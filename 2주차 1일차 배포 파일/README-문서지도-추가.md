# README.md 문서 지도에 추가할 줄 (**내용만 붙여넣는** 조각)

> **사용 방법**
> 1. 저장소 루트의 `README.md`를 엽니다. 정리 담당이 `## 문서 지도` 표 **맨 아래에 아래 줄을 이어서** 붙입니다. 다른 사람은 고치지 않고 PR에 댓글을 남깁니다.
> 2. 단계 칸은 `2-1`처럼 `주차-일차`로 씁니다. 상태는 올린 뒤 `☑`로 바꿉니다.
> 3. 오늘 만든 파일 **6개**를 한 줄씩 씁니다. 실제로 만들지 않은 파일은 줄을 넣지 않습니다.
> 4. 이 파일 자체는 저장소에 올리지 않습니다.
