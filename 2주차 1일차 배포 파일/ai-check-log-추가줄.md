# ai-check-log.md에 이어 쓸 줄 (복사하지 않고 **내용만 붙여넣는** 조각)

> **사용 방법**
> 1. 저장소의 `docs/domain/ai-check-log.md`를 엽니다. 지난 시간에 만든 `## 요구사항 정리 (1주차 2일차~)` 섹션 표 **맨 아래에 줄만 이어서** 씁니다. **새 섹션을 만들지 않습니다.**
> 2. 아래 표의 한 줄 형식을 따릅니다. 예시는 베끼지 말고 우리 팀 내용으로 바꿉니다.
> 3. 오늘 최소 **팀당 3줄**, 그중 **'보류' 1개 이상**입니다. 버린 것을 적는 게 더 중요합니다.
> 4. 이 파일 자체는 저장소에 올리지 않습니다.

## 붙여넣을 형식

| 날짜 | 쓴 사람 | 어디서 | AI가 말한 것 | 확인 결과 | 채택/보류 | 이유 |
| --- | --- | --- | --- | --- | --- | --- |
| YYYY-MM-DD | (이름) | 스토리 초안 | | | | |

## 어디서 칸에 쓸 값 (2주차 1일차)

| 어디서 | 언제 |
| --- | --- |
| 스토리 초안 | 블록 1 ② 뒤 |
| 스토리 거르기 | 블록 1 ③ (버린 것) |
| 제안서(v2) 비교 | 블록 3 A조 ② |
| 매일 기록 초안 | 블록 3 마지막 (고친 것이 있을 때) |
